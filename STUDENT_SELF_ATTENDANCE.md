# Student Self Attendance

Students can now open **Student Portal -> Mark Attendance**, select a subject from their own department/semester, and mark themselves Present for today.

Rules enforced by the backend:
- Student must be logged in.
- Student can only mark their own attendance.
- Only today's date is accepted.
- Subject must belong to the student's department and semester.
- A student can mark a subject only once per day.
- Student self-attendance is always saved as `Present`.

The existing admin attendance flow remains unchanged.
